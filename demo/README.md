# modelmeta demo — portable model checkpoint metadata in 45 seconds

**This is the modelmeta proof: a model checkpoint, its metadata sidecar, and offline byte verification moving together as one portable artifact.**

[![Watch the modelmeta demo](modelmeta-demo.gif)](modelmeta-demo.mp4)

[Download the full-quality MP4](modelmeta-demo.mp4) · [Open the Remotion source](mm-video/src/Demo.tsx)

The film is a 44.95-second, 1080×1080 Remotion composition with a single Deepgram Flux Hannah narration, deterministic UI sound effects, and real values generated by the reproducible example below.

## The reproducible example

`examples/` contains a deterministic synthetic regression checkpoint and its hash-linked sidecar:

- `score_model.pkl` — a scikit-learn model trained on 300 synthetic study-hours → exam-score rows; R² 0.9213 and RMSE 4.1423 on the held-out split.
- `score_model.pkl.modelmeta.yaml` — sidecar containing the dataset digest, training snapshot, elapsed timing, and checkpoint SHA-256.

This is intentionally synthetic demo data. It is not a dataset of real students and is not a production model.

The checkpoint is a pickle. `modelmeta verify` hashes it without deserializing it; never load an untrusted pickle merely because verification returns `match`.

```bash
modelmeta inspect demo/examples/score_model.pkl
modelmeta verify demo/examples/score_model.pkl   # exit 0: match
```

## Reproduce the example

From the repository root:

```bash
uv run --with numpy --with scikit-learn python demo/make_example.py
```

The script rewrites `demo/examples/score_model.pkl` and its sidecar, then verifies the pair. The model/data generation is seeded, so the checkpoint bytes and checkpoint SHA-256 are stable; `created_at` and elapsed timing in the sidecar are expected to vary when the command is rerun.

The plotted points behind the film's scatter scene live in [`mm-video/src/data.ts`](mm-video/src/data.ts).

## Re-render the film

```bash
cd demo/mm-video
npm install
npx remotion render ModelmetaDemo ../modelmeta-demo.mp4
```

The film is deterministic code in [`mm-video/src/Demo.tsx`](mm-video/src/Demo.tsx). Voiceover files live under `mm-video/public/vo/`; procedural sound effects live under `mm-video/public/sfx/`.

The final GIF is the lightweight preview. The MP4 is the full-quality deliverable and is the target of the clickable GIF above.

## Product claim

modelmeta proves that the bytes being checked match the sidecar's recorded digest. It does not prove the truth of the dataset, code, metrics, hardware, author, or model-quality claims. Those claims remain self-asserted in v0.1.
